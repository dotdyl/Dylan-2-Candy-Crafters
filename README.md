# Dylan^2 Candy Crafters

Application created for Oregon State University CS340: Introduction to Databases, course Final Project.

# Web Application Pages for supporting CRUD Operations [Create, Read, Update, Delete]
- Home 
- Candies
- Orders
- Inventory Spaces
- Vendors

# Tech Stack
### Frontend
- Framework: React with Vite
- Styling: TailwindCSS
  - UI Components: DaisyUI
### Backend
- Framework: ExpressJS
- Runtime: NodeJS
### Data 
- Database: MariaDB
- Procedural SQL: PL/SQL
